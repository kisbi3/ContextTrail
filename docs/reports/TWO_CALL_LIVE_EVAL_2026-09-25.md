# 두 호출 그래프 분석 · 첫 실제 표본 평가

2026-09-25. `측정 프로젝트`의 한 Codex 세션에서 연속된 14개 기록(27,230자)을 선별해 원문을 확인한 뒤, 별도 임시 평가 상태에서 실행했다. 이 표본은 설계 논의, 문서 수정 요청, 도구 실행 결과, 완료 보고를 포함한다. Claude는 로그 입력만 수집하며 평가 Runner는 Codex CLI였다. 실제 `측정 프로젝트` 상태 DB와 원본 프로젝트는 수정하지 않았다.

원문과 결과를 대조한 범위에서 그래프는 **설계 보완 제안 → 진행 순서 제안 → 문서 반영 요청 → 로컬 문서 수정 확인과 프롬프트 작성 보고**를 구분했다. 문서 수정은 원래 도구 결과와 성공 종료 코드로 뒷받침했으며, 프롬프트를 다른 세션에 실제로 전송했거나 제품 코드를 고치고 PR을 머지했다고 주장하지 않았다. 미래 작업은 미해결 사항으로 남겼다. 조건부 재검토도 문서 편집·검사 확인을 프로젝트 전체 구현 성공으로 확대하지 않았다.

## 이 평가에서 발견해 고친 결함

1. `ReadRequest`의 `oneOf`가 Codex 구조화 출력 API에서 거부됐다. 단일 객체 스키마와 요청 종류별 호스트 검증으로 수정했다.
2. 긴 도구 출력의 인용이 정확한 전체 줄과 다르면 추출이 실패했다. 제공 범위 안의 **유일한 정확한 부분 문자열**만 정규화하도록 하고, 만들어낸 문구와 중복 문구는 거부한다.
3. 정규화한 근거와 후보 응답의 줄 범위가 달라 다음 단계 재검증이 실패했다. 검증된 후보 인용도 원문 줄로 정규화해 재사용했다.
4. 유효한 추출 초안을 통합 전에 의미상 위험 신호만으로 다시 추출해, 유효한 초안까지 버리는 경로가 있었다. 추출 단계의 추가 호출은 계약 실패 복구에만 사용하고 의미 재검토는 GraphDelta 뒤에서 수행한다.

이후 과거 근거의 시점 불명확 사례까지 보강한 최종 코드의 필수 합성 시험은 **199개 통과**했다. 위 실패 실행들은 모두 평가용 임시 상태에서 끝났으며 실제 프로젝트 그래프 게시가 없었다.

## 해석 범위와 다음 검증

이 결과는 **한 세션의 한 WorkUnit**에 대한 수동 근거 대조다. 기존 방식과 같은 입력을 사용한 A/B 비교, 과거 그래프 검색이 필요한 여러 WorkUnit, 독립적인 재시도·철회·교차 세션 연결의 품질은 아직 검증하지 않았다. 따라서 정확도 개선율이나 전체 프로젝트의 의미 품질을 주장하지 않는다. 추가로 자연스럽게 이어지는 3~5개 WorkUnit에서 검색 누락과 잘못된 관계·상태 변경을 확인해야 한다.

평가 원문·모델 응답·근거 발췌는 저장소에 넣지 않았다. 로컬 임시 평가 결과는 `<review-dir>/`에 owner-only 권한으로 남아 있으며, LangSmith 전체 내용 trace에도 비공개 대화와 코드가 포함된다.
