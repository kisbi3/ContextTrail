# 다음 작업: 터미널 연결선과 화면 구성 (2026-09-26 합의)

소유자와 합의한 범위. 진행 전 compact 대비 메모다.

## 이번에 할 것 (2026-09-26 구현 완료)

1. **도착 쪽에 출발 번호 적기**
   - 여백 레일의 도착 표시를 `─동기─▶`에서 `[02] 동기 ▶`로 바꾼다. 선을 따라 올라가지 않아도 출발 상자를 안다.
   - 요청 괄호(대화 순서)도 같은 형식을 쓴다.
   - 위치: `diagram.flow_diagram`의 레일 그리기. `tests/test_diagram.py`의 `─동기─▶`·`─답변─▶`·`─후속─▶` 단언을 함께 고친다.
2. **요청 목록 칸과 요청 단위 흐름**
   - 왼쪽에 요청(사용자 발화, `actor=user` 사건) 목록을 둔다. 각 줄은 상태 표식과 번호, 한 줄 제목이다. `[` `]`로 요청 사이를 이동한다.
   - 가운데 흐름은 선택한 요청의 차례만 그린다. 범위는 그 요청부터 다음 요청 전까지다. 차례 밖 사건과의 연결은 참조로 남긴다.
   - 전체 흐름 보기 전환은 남긴다.
   - 좁은 화면에서는 요청 목록을 접고 두 칸만 쓴다.
   - 위치: `ui.FlowPanels`(`TerminalApp`·`GraphApp` 공용).
3. **연결 따라가기**
   - 상세 칸(`render.event_detail`의 "연결된 사건")의 연결에 1~9 번호를 붙이고, 숫자키로 그 사건으로 이동한다.
   - 이동 기록을 두고 뒤로 가기를 둔다. 키는 정한다(예: Backspace).
4. **선택한 상자의 연결 강조**
   - 상자를 고르면 이어진 상자와 그 사이 선·표시만 밝게 하고 나머지는 흐리게 한다.
   - `Cell`에 어느 연결에 속하는지 정보가 필요하다.

- **검증:** PTY 캡처를 PNG로 소유자에게 보낸다. 캡처 스크립트는 세션 scratchpad의 `tui_shot.py`이고, PNG 변환은 메모리의 QuickLook 방법을 따른다. 전체 시험을 통과시키고 README·DECISIONS·CLAUDE.md를 갱신한다.

## 나중에 (합의했지만 뒤로 미룸)

2026-09-26 `!`·`/`·`z`·`?`와 마우스를 구현했다. 남은 것은 먼 연결 표시 통일뿐이다.


- `n`/`N`: 확인 필요한 곳(미검증 변경, 실패, 답 없는 요청)으로 이동
- `/`: 제목·파일 이름 검색
- `z`: 한 칸 크게 보기
- `?`: 전체 단축키 도움말
- 먼 연결을 여백 선 대신 받는 상자의 `← [02] 동기`로 통일(1·2 적용 뒤에도 복잡할 때)
